## Changes / decisions
- The dialogues and the Praktikum text are my own versions based on the ASR; not claimed verbatim. The ASR had Köln/Kiel and Vormittag/Nachmittag uncertainties, so the wording was kept simple and consistent.
- Ja/nein/doch: standard rule (doch answers a negative question positively; nein agrees with the negative). The teacher's version is the same.
- und/oder/aber: added the comma rule for aber, the word-order warning (aber does not count as a position) and the same-subject ellipsis.

## Differences between the teacher and standard German
- Student sentence "aber heute trinka ich Tee" corrected as the model "aber heute trinke ich Tee".
- Teacher wrote "trinken keinen Kaffee" for ich; the Day uses "trinke".
- "einer Kollegen grüßen" in the oral reading of the book options is a slip; the Day uses "einen Kollegen grüßen" (grüßen + accusative).
- Teacher advice about past tenses is kept as advice to use the present tense; only war/hatte are known so far.
