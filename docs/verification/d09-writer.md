## 3. Corrections
1. Old rule "kein only negates 'a/an' + noun" → kein also negates bare nouns (keine Busse, keine Zeit, kein Fleisch); nicht for verbs, adjectives, names, der/die/das nouns, places. Why: standard German; R4. H.
2. Old table header "kein, keine, keinen" and say line "kein, keine, keinen" → removed keinen (Akkusativ = Tag 11); table now Nominativ only, with pointer to Tag 11. H.
3. Old story section: "someone finds her Fahrrad has a flat tyre" and the invented line "Puh, das war knapp, so ein Glück!" → removed. Real KB p.32 sentences used: "Heute kein Test! So ein Glück!", "Oh, nein! Keine Fahrkarte?!", "Ach nee, kein Bus. Also schnell! Wo ist die U-Bahn?", "Oje, kein Fahrrad! Schnell, da ist ein Bus.", "Ich gehe zu Fuß! Jetzt aber schnell!". A flat tyre is not stated in the book. H (read on page). Frame letters: A given in the book (item 3 = A); the others (B 2, C 1, D 5, E 4) are my reading of the pictures: M-H.
4. Old exam tip ("Hören plays Bildgeschichte-style stories", R5) → replaced with real model-test facts (Lesen Teil 3 sign + item 15, Hören Teil 1 six conversations twice, Sprechen Teil 3 Bitten). H.
5. Old vocab 'der Mensch', 'die Brille', 'die Uhr' removed: not Day 9 words in the book chapter (only examples in class). They remain usable in examples (Brille/Uhr in the class example is kept as sentence, hover via gloss). Menschen kept in gloss. M.
6. Teacher "Wir hören Musik nicht" → not used; correct pattern "Wir hören keine Musik" is not in the Day as a sentence but the rule covers it (bare noun → kein). H.
7. Teacher "Nehmen Sie Bus Nummer neun" → replaced by "Nehmen Sie die U-Bahn": with a masculine noun the standard form is "den Bus" (Akkusativ, Tag 11); the bare "Bus Nummer neun" is possible but I am not sure it is a good A1 model. M.
8. Teacher "Kochen Sie Pizza" → "Kochen Sie Reis": one does not usually "cook" a pizza (backen/machen). M-H.
9. Old paragraph "A1 only expects three direction words" → kept as "for A1 three direction words are enough" (the book lists only these). H.
10. Old warn "Gehen Sie = command, Sie gehen = statement" → kept but now also says that verb-first without punctuation can be a Ja/Nein-Frage ("Gehen Sie nach links?"). H.
11. Teacher "Imperative: put the verb first then the object" → "verb in position 1, then Sie" (KB p.37: "Das Verb im Imperativ steht auf Position 1"). H.
