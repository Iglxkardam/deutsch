## 2. Corrections
1. **Plural tiles and "five patterns"** — before: heading and text say "five plural patterns", but six tiles, labelled "¨ + e" and "¨ + er" (as if the umlaut were always there, while the tile's own example is Tag → Tage), "–" for no change, plus a sixth "+ nen" tile presented as if it were a pattern. After: the paragraph names the book's five patterns exactly as KB p.23 8b / p.27 print them ((¨)–, (¨)-e, (¨)-er, -(e)n, -s), explains that (¨) means "sometimes with an umlaut" (Tag → Tage vs Arzt → Ärzte), and says the sixth tile (-in → -innen) is the -(e)n pattern with a doubled n, not a sixth pattern. Tile labels now "(¨) –", "(¨) + e", "(¨) + er", "-in → -innen". The -(e)n tile's second example is now der Patient → die Patienten, so that both -n and -en appear. Why: the old tiles taught that -e and -er plurals always take an umlaut, and the count did not add up. H. Source: KB p.23 8b, p.27 box.
